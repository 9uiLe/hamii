## Missing information and decision

The smallest useful supplement is a binding-to-state table for I01 and I02 across S0/S1/S2. It must name each source field/expression and define availability, visibility, and fallback output for loading/unavailable and nil values. For I02, if it is derived from `createdAt`, it must say so and specify exact text transformation (including date format, locale/time zone, and nil behavior); if it is another source, identify that source. It must also define whether a cached profile counts as `normal` while reloading and whether I01 and I02 share a state gate. A bare list of states cannot determine outputs. The present dependency graph is useful topology but needs predicate/transform annotations or an accompanying binding-to-state relation; adding untyped edges alone is insufficient.
